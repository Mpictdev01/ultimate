## 1. Login & Akses

Untuk mengakses halaman admin, silakan kunjungi alamat website Anda diikuti dengan `/admin`.
Contoh: `ultimateautoshopindonesia.com/admin`

*   **Email**: Masukkan email admin yang terdaftar.
*   **Password**: Masukkan password admin.
*   Klik tombol **Login** untuk masuk.

> **Catatan**: Pastikan menjaga keamanan email dan password Anda.

---

## 2. Dashboard

Halaman utama yang muncul setelah login adalah **Dashboard**. Halaman ini memberikan ringkasan statistik website Anda secara real-time.

**Fitur Dashboard:**
*   **Ringkasan Statistik**: Menampilkan jumlah total item untuk:
    *   Portfolio
    *   Articles (Artikel)
    *   Testimoni
    *   Services (Layanan)
*   **Quick Actions (Aksi Cepat)**: Tombol pintas untuk melakukan tugas umum dengan cepat:
    *   Tambah Portfolio baru
    *   Tambah Artikel baru
    *   Tambah Testimoni baru
    *   Akses Pengaturan Website

## 3. Manajemen Konten

Bagian ini adalah inti dari Admin Panel, di mana Anda bisa menambah, mengubah, dan menghapus konten yang tampil di website utama.

### 3.1. Portfolio
Menu ini digunakan untuk mengelola daftar proyek atau hasil pengerjaan bengkel yang akan ditampilkan di halaman Portfolio.

*   **Lihat Daftar**: Menampilkan semua portfolio yang ada beserta gambar utamanya.
*   **Tambah Baru**:
    *   Klik tombol "Add New".
    *   Isi **Judul** proyek.
    *   Isi **Deskripsi** singkat.
    *   Upload **Gambar** proyek (pastikan kualitas gambar baik).
    *   Atur tanggal pengerjaan (opsional).
    *   Klik **Save** untuk menyimpan.
*   **Edit**: Klik tombol/ikon edit pada item yang ingin diubah.
*   **Hapus**: Klik tombol/ikon hapus untuk membuang portfolio selamanya.

### 3.2. Articles (Artikel)
Menu ini untuk mengelola blog atau artikel berita seputar otomotif.

*   **Tambah Artikel**:
    *   Isi **Judul** artikel.
    *   Upload **Cover Image** (Gambar sampul).
    *   Tulis **Konten** artikel pada editor teks yang tersedia.
    *   Pilih **Kategori** atau **Tag** jika ada.
    *   Klik **Publish** untuk menayangkan.

### 3.3. Testimoni
Kelola ulasan pelanggan yang tampil di halaman depan (homepage) atau halaman testimoni.

*   **Tambah Testimoni**:
    *   **Nama Klien**: Masukkan nama pelanggan.
    *   **Pekerjaan/Role**: (Opsional) Contoh: "Pengusaha", "Karyawan Swasta".
    *   **Isi Testimoni**: Ketik ulasan positif mereka.
    *   **Foto Klien**: Upload foto profil klien jika ada.
    *   **Rating**: Berikan jumlah bintang (1-5).

### 3.4. Gallery
Menu ini kemungkinan digunakan untuk galeri foto umum bengkel atau kegiatan.

*   Upload banyak gambar sekaligus untuk ditampilkan dalam grid galeri website.
*   Bisa menambahkan caption/keterangan singkat pada setiap foto.

### 3.5. Services (Layanan)
Atur daftar layanan yang ditawarkan bengkel Anda (Contoh: Coating, Detailing, Paint Protection).

*   **Nama Layanan**: Judul layanan.
*   **Deskripsi**: Penjelasan detail tentang layanan tersebut.
*   **Harga**: (Opsional) Rentang harga layanan.
*   **Icon/Gambar**: Representasi visual layanan.

### 3.6. Features (Fitur Unggulan)
Biasanya digunakan untuk menampilkan kelebihan bengkel di halaman depan (Contoh: "Pengerjaan Cepat", "Bergaransi", "Teknisi Profesional").

*   Kelola poin-poin keunggulan bisnis Anda di sini agar tampil menarik di homepage.

## 4. Pengaturan Website (Settings)

Menu **Settings** digunakan untuk mengatur informasi global website.
Fitur yang biasanya tersedia:
*   **Informasi Dasar**: Ubah Judul Website, Deskripsi SEO.
*   **Kontak**: Ubah Nomor WhatsApp, Email, Alamat Bengkel.
*   **Sosial Media**: Atur link ke Instagram, Facebook, TikTok bengkel.
*   Perubahan di sini akan otomatis terupdate di bagian Header (Atas) dan Footer (Bawah) website.

---

## 5. Manajemen Pengguna (Users)

Menu ini khusus untuk mengelola siapa saja yang bisa mengakses Admin Panel.
*   **Tambah Admin**: Daftarkan tim baru agar bisa login dan membantu mengelola web.
*   **Ubah Password**: Reset password admin jika lupa atau untuk keamanan berkala.
*   **Hapus Admin**: Mencabut akses admin yang sudah tidak aktif.

---

## 6. Logout

Selalu pastikan untuk menekan tombol **Logout** di pojok kiri bawah sidebar setelah selesai mengelola website, terutama jika menggunakan komputer umum, untuk menjaga keamanan data website Anda.
